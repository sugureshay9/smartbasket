# SmartBasket - Complete Setup & Deployment Guide\n\n## 🚀 Quick Start (5 minutes)\n\n### Prerequisites\n```bash\nNode.js 18+\nMongoDB Atlas (free tier ok)\nRedis (cloud or local)\ngit\n```\n\n### 1. Clone Repository\n```bash\ngit clone https://github.com/sugureshay9/smartbasket.git\ncd smartbasket\n```\n\n### 2. Setup Backend\n```bash\ncd server\nnpm install\ncp ../.env.example .env.local\n# Edit .env.local with your credentials\nnpm run dev\n# Backend runs on http://localhost:5000\n```\n\n### 3. Setup Frontend\n```bash\ncd ../client\nnpm install\nnpm run dev\n# Frontend runs on http://localhost:3000\n```\n\n### 4. Setup Mobile\n```bash\ncd ../mobile\nnpm install\nnpm start\n# Scan QR code in Expo app\n```\n\n---\n\n## 📚 Complete Deployment\n\n### Backend Deployment (Railway)\n\n1. **Create Railway Account**\n   - Go to [railway.app](https://railway.app)\n   - Sign up with GitHub\n\n2. **Deploy Code**\n   ```bash\n   npm install -g @railway/cli\n   railway login\n   cd server\n   railway up\n   ```\n\n3. **Add Environment Variables**\n   - MongoDB URI\n   - Redis URL\n   - JWT Secret\n   - External Price API URL\n\n4. **Access Backend**\n   - https://your-railway-app.up.railway.app/api\n\n### Frontend Deployment (Vercel)\n\n1. **Create Vercel Account**\n   - Go to [vercel.com](https://vercel.com)\n   - Connect GitHub\n\n2. **Deploy Frontend**\n   ```bash\n   npm install -g vercel\n   cd client\n   vercel --prod\n   ```\n\n3. **Add API URL**\n   - Set `NEXT_PUBLIC_API_URL` to your Railway backend URL\n\n4. **Access Frontend**\n   - https://your-vercel-app.vercel.app\n\n### Mobile Deployment (Play Store)\n\nSee [docs/PLAYSTORE.md](./PLAYSTORE.md) for complete guide.\n\n**Quick version:**\n```bash\ncd mobile\neas build --platform android --release\neas submit --platform android --latest\n```\n\n---\n\n## 🔑 Environment Variables\n\n### Backend (.env.local)\n```env\n# MongoDB\nMONGODB_URI=mongodb+srv://user:pass@cluster.mongodb.net/smartbasket\n\n# Redis\nREDIS_URL=redis://localhost:6379\n\n# External Price Server\nEXTERNAL_PRICE_API=https://api.example.com/prices\nEXTERNAL_PRICE_API_KEY=your_api_key\n\n# JWT\nJWT_SECRET=your_secret_min_32_chars\nJWT_REFRESH_SECRET=your_refresh_secret\n\n# Cloudinary\nCLOUDINARY_CLOUD_NAME=your_cloud\nCLOUDINARY_API_KEY=your_key\nCLOUDINARY_API_SECRET=your_secret\n\n# App\nNODE_ENV=development\nPORT=5000\nCLIENT_URL=http://localhost:3000\n```\n\n### Frontend (.env.local)\n```env\nNEXT_PUBLIC_API_URL=http://localhost:5000/api\n```\n\n### Mobile (.env)\n```env\nEXPO_PUBLIC_API_URL=http://localhost:5000/api\n```\n\n---\n\n## 📊 API Endpoints\n\n### Auth\n```\nPOST   /api/auth/register\nPOST   /api/auth/login\nPOST   /api/auth/refresh-token\n```\n\n### Products\n```\nGET    /api/products/search?q=sugar\nGET    /api/products/:productId\nGET    /api/products/prices/compare/:id  [Protected]\n```\n\n### Alerts\n```\nPOST   /api/alerts                        [Protected]\nGET    /api/alerts                        [Protected]\nDELETE /api/alerts/:alertId               [Protected]\nGET    /api/alerts/check/triggered        [Protected]\n```\n\n### Admin\n```\nGET    /api/admin/dashboard/stats         [Admin Only]\nGET    /api/admin/users                   [Admin Only]\nGET    /api/admin/products                [Admin Only]\nGET    /api/admin/stores                  [Admin Only]\n```\n\nSee [docs/API.md](./API.md) for complete API documentation.\n\n---\n\n## 📁 Project Check Redis connection\nredis-cli ping\n\n# Check environment variables\ncat .env.local\n\n# Clean install\nrm -rf node_modules\nnpm install\nnpm run dev\n```\n\n### Frontend build fails\n```bash\n# Clear Next.js cache\nrm -rf .next\n\n# Reinstall\nrm -rf node_modules\nnpm install\nnpm run build\n```\n\n### Mobile build fails\n```bash\n# Clear Expo cache\nexpac clear\n\n# Full rebuild\nrm -rf node_modules\nnpm install\nnpm start --clear\n```\n\n---\n\n## 📱 Features Status\n\n| Feature | Status | Details |\n|---------|--------|----------|\n| Authentication | ✅ Complete | JWT, refresh tokens
